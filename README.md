# Civic Connect

Civic Connect is a civic-tech project focused on improving public service access and community engagement. The repository includes the project app and related frontend work.

## Overview

This repo contains a React-based application with multiple app modules and frontend components for civic service or community-oriented functionality.

## Project Structure

- `civica-app/` — main frontend app
- `civica-app/civica-live/` — additional app or live interface

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/VedanthRai/civic-connect.git
   cd civic-connect
   ```
2. Navigate to the app folder you want to run.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Notes

- Review the app-specific README files for module setup instructions.
- Keep environment variables and secrets out of version control.
